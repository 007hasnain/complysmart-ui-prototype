ComplySmart v1.1 — Evidence-Backed MBA Research Prototype
==========================================================

DEPLOY TO EXISTING NETLIFY SITE
1. Open your existing Netlify project (for example complysmart-ai.netlify.app).
2. Go to Deploys.
3. Drag this entire unzipped folder into the manual deploy area.
4. Netlify will publish index.html and keep the same site URL.

CUSTOM DOMAIN (recommended for the university-facing link)
1. In Netlify: Domain management > Add a domain.
2. Use a subdomain you control, e.g. complysmart.yourdomain.com.
3. Follow Netlify's DNS instructions.
4. Keep the current *.netlify.app URL as a backup.

VERSION CONTROL
- Treat this package as ComplySmart v1.1.
- Keep the ZIP unchanged as the archived submission version.
- Store a copy in GitHub/OSF/Zenodo if desired for long-term preservation.

DATA BOUNDARY
- The overlap intelligence uses the MBA requirement-level research matrix (64 requirements, 19 programs).
- Official/public sources are linked in the interface.
- Facility-specific audit reports are NOT included or disclosed.
- Supplier/CAPA values are clearly marked illustrative.
- Overlap does not mean equivalence or mutual recognition.
